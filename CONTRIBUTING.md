# Como contribuir

Contribuições são bem-vindas. Abra uma issue para conversar sobre mudanças maiores antes de começar a implementação.

## Desenvolvimento

1. Instale Python 3.10 ou superior, FFmpeg e FFprobe.
2. Crie um ambiente virtual e instale as dependências de desenvolvimento com `py -3.12 -m pip install -e ".[dev]"`.
3. Execute `py -3.12 -m pytest` antes de abrir uma solicitação de alteração.
4. Mantenha a interface, a leitura de mídia e a conversão em seus módulos. Não anuncie recursos que ainda não existem.

Descreva as alterações, informe como reproduzir problemas corrigidos e inclua capturas de tela de mudanças visuais quando disponíveis.
